# Jaktlaget 1.5.3

Korrigering av redigeringsflödet för registrerat vilt.

- När Ändra väljs öppnas exakt den befintliga registreringens värden.
- Djurslag, klass, vuxenekvivalent, datum, pass, skytt, mottagare, fördelning, kassationsstatus och kommentar bevaras i formuläret.
- Standardvärden används endast när en helt ny registrering öppnas.
- Ungdjur får fortsatt automatiskt 50 procent och vuxet djur 100 procent när användaren aktivt byter typ i en ny eller befintlig registrering.
- Data från 1.5.2, 1.5.1 och 1.4.4 migreras vidare.
